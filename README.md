## 实测促销规则矩阵（2026-10-12）

门店（beType=6 企业团餐）。共 12 条规则：

| 门槛 | GMS001 保鲜速达（默认可用） | GMS002 专人分餐（需提前4h） | GMS003 专人摆台（需提前4h） |
|---|---|---|---|
| ¥300 | 7.8 折（减22%） | 8.8 折（减12%） | 9.3 折（减7%） |
| ¥500 | **7.4 折（减26%）** | 8.4 折（减16%） | 8.9 折（减11%） |
| ¥1000 | 7.0 折（减30%） | 8.0 折（减20%） | 8.5 折（减15%） |
| ¥2000 | 6.6 折（减34%） | 7.6 折（减24%） | 8.1 折（减19%） |

**GMS001 在每一档都最优，且默认可用** —— 优化主轴是「选 GMS001 + 把餐品小计推上更高门槛」。

### 关键字段：`enjoyable.balance`

`calculate-price` 直接返回凑单差额。实测 ¥780 餐品订单：

```json
{ "realDiscount": 7.4 }                          // enjoyed：已享折扣
{ "realDiscount": 7.0, "balance": 22000 }       // enjoyable：再买 ¥220 → 7.0 折
```

`balance = 22000` 分 = 下一档门槛 ¥1000 − 当前餐品小计 ¥780。**服务端已算好差额，无需反推。**

## 安装与集成

### 作为 WorkBuddy 技能使用

1. 配置麦当劳 MCP（详见 `mcp-config.example.json`，Token 用环境变量占位符）：
   ```json
   {
     "mcpServers": {
       "mcd-mcp": {
         "url": "https://mcp.mcd.cn",
         "headers": { "Authorization": "Bearer ${MCD_MCP_TOKEN}" }
       }
     }
   }
   ```
2. 在 WorkBuddy 连接器管理页对 `mcd-mcp` 点【信任】启用。
3. 把本仓库 `SKILL.md` 加载为技能，对话中直接说「帮我们部门凑个团餐」即可。

### 作为独立算法库使用

```python
from promotion_ladder import parse_promotions, recommend

ladders = parse_promotions(raw_query_promotions_data)        # MCP 返回的 data 数组
recs = recommend(ladders, subtotal_cents=78000,
                 gm_service_codes=["GMS001", "GMS002", "GMS003"])
print(recs[0].as_dict())   # 最优方案 + 凑单差额，纯函数、零网络 IO
```

## 算法三层

| 层 | 职责 | 说明 |
|---|---|---|
| 规则解析层 | 满折阶梯 → 可比较门槛表 | 解析 `query-promotions` 原始 JSON |
| 组合搜索层 | 枚举服务 × 商品 × 券，多次算价取最小 | 折扣由服务端自动匹配，策略即枚举 + 取优 |
| 差额提示层 | 读 `enjoyable.balance` | 输出「再买 ¥X → 降到 Y 折」 |
